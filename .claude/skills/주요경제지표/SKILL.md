# /주요경제지표 — 경제지표 엑셀 자동 갱신

## 실행

```powershell
python scripts/econ_indicators.py                    # 가장 최근 화요일 기준
python scripts/econ_indicators.py --date 2026-07-14  # 날짜 지정
python scripts/econ_indicators.py --fetch-only       # 수집·보정 확인만 (엑셀 미변경)
python scripts/econ_indicators.py --no-fix-revisions # 이전 호 보정치를 반영하지 않고 동결(예외)
```

> 보정 반영은 **기본 동작**이다(팀 방침 2026-07-15). 매 호 이전 값 보정을 항상 반영한다.

작업 폴더: `001. 뉴스레터\003. 경제지표\`

## 워크플로우

1. **날짜 확인** — 대상 화요일(기본: 가장 최근 화요일)을 사용자에게 보여주고 확인.
   2주 전 = -14일, 1달 전 = -28일, 작년 말은 표 시트에 고정값이므로 건드리지 않는다.
2. **수집 실행** — 스크립트 실행. 다음 상황이면 반드시 사용자에게 보고:
   - `⚠️ 휴장/미제공 → 직전 영업일 값 사용` 경고 (휴일 폴백 — 팀 규칙: 한국 설/추석은 전날 값)
   - `⚠️ 페트로넷 미업로드 → Investing 대체` 경고 (유가 딜레이 폴백 — 최종안 전 페트로넷 값 재확인)
   - `🔄 보정치 감지` — 2주 전·1달 전 저장값이 소스에서 사후 수정된 경우. **기본으로 raw data에 반영**하고
     보정 전·후 값을 반드시 사용자에게 보고한다 (Investing·페트로넷 11개 지표 전부 대조).
     발행된 호와 수치를 동결하려는 예외 상황에만 `--no-fix-revisions`.
   - `🔺 급등락 확인 권장` 경고 (2주 변동 ±10% 이상 또는 국채 ±50bp 이상)
3. **기준 파일 주의** — 기본값은 폴더에서 파일명 날짜가 가장 최근인
   `최신 경제지표 데이터(YYYY-MM-DD).xlsx`. 미완성 "복사본" 파일이 남아 있으면
   그것이 잡힐 수 있으므로 `--base`로 직전 호 완성본을 명시하는 것이 안전하다.
   출력 파일이 이미 존재하면 스크립트가 중단한다(덮어쓰기 안 함).
4. **검증** — 스크립트가 출력하는 "갱신된 표"와 유가 교차 검증 결과를 사용자에게 보여주고,
   엑셀을 열어 표·차트 확인을 요청한다. 검증 전에 완료 선언 금지.
   변동 내역은 인라인 QA 대시보드(visualize 위젯)로 시각화해 보여준다 — 파일 생성 없이 인라인으로만.
   대시보드 철학: "예쁜 금융 대시보드"가 아니라 GitHub Actions/Datadog 같은 **운영·검증(QA) 대시보드**.
   구성: ①상단 상태 칩(수집 N/N, 보정 건수, 교차검증) ②"오늘 확인 필요" 체크리스트
   ③이전 호 보정 이력 표(보정 전 → 보정 후 → 차이 → 반영✓) ④예외(보정/단일소스/급등) 카드를
   정상 카드보다 먼저 배치, 보정 발생 시 연노랑 배경 ⑤카드 클릭 시 직전호·1달 전·일별 원자료.
   최신 스냅샷: KITA-INDICATOR 리포 `dashboard/dashboard_v3.html`.
5. **한글(.hwp) 반영은 이 스킬 범위 밖** — 클로드 채팅 "설명글 작성" 프로젝트가 전담
   (사용자 결정, 2026-07-15). HWP용 텍스트를 출력하지 않는다.
6. 상세 명세·검증 기준값: `001. 뉴스레터\003. 경제지표\주요경제지표_자동화_검증명세.md`

## 기술 메모

- 엑셀 쓰기는 **Excel COM**(pywin32) 사용 — openpyxl 저장은 도형·차트 손상 위험이 있어 금지.
- Investing API: `api.investing.com/api/financialdata/historical/{id}` + `domain-id: www` 헤더, 로그인 불필요.
- 페트로넷: `POST /v4/sub.jsp` 2회 — ① 메뉴 진입(fmuId=KDFQSTAT, smuId=KDFQ01, tmuId=KDFQ0100)으로
  세션 초기화 ② 조회 버튼(checkit)이 만드는 폼을 재현해 기간 조회. 핵심 필드:
  `Parameter=":T='D',:FromDate='YYYYMMDD',:ToDate='YYYYMMDD',:ProdCD='\'001\'\,\'002\'\,\'003\' '"`,
  `InitialLoadFile=국제가격정보(일일국제원유가_EXT)(intruser1)`, 날짜 셀렉트는 **b*=시작일, a*=종료일**
  (이름이 직관과 반대). 휴장일 값은 `-`로 오므로 해당 유종만 건너뜀.
  사용자 수동 절차(국제석유통계>국제석유가격>일일국제원유가격, Oman 제외)와 동일 화면의 데이터다
  (2026-07-15 사용자 스크린샷 6/30~7/14 전체 행 일치 확인).
