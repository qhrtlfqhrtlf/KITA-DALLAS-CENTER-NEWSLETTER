## ⚠ 조사 환경 제약 (등급 산정에 직접 영향)

이 세션의 네트워크 정책이 **외부 사이트 직접 접속(WebFetch)을 차단**한다. 검색은 가능하다.
→ 따라서 현재 확보 가능한 근거는 v2 §3-F **우회 경로 ②(공식 도메인 인덱싱 스니펫)** 수준이며, v2 §3-F 규칙에 따라 **`✅✅` 부여가 원칙적으로 불가**하다.
- 공식 도메인 스니펫 1건 → `✅`
- 공식 도메인 스니펚 + 독립 공식 보도자료(예: SEMI 공식 + PR Newswire + 개최도시 공식) → 예외적으로 `✅✅` 인정 (복수 1등급 소스가 문자열까지 일치하는 경우에 한함)
- 집계 사이트만 존재 → `⚠` 고정 (v2 §3-E)

**해소 방법**: 환경의 네트워크 정책을 완화(도메인 허용)하면 공식 페이지 직접 확인으로 등급 승급 가능. Phase 2 착수 전 결정 필요.
