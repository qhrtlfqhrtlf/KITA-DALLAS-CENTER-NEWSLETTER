## ⚠ 조사 환경 제약 (등급 산정에 직접 영향)

이 세션의 네트워크 정책이 **외부 사이트 직접 접속(WebFetch)을 차단**한다. 검색은 가능하다.
→ 따라서 현재 확보 가능한 근거는 v2 §3-F **우회 경로 ②(공식 도메인 인덱싱 스니펫)** 수준이며, v2 §3-F 규칙에 따라 **`✅✅` 부여가 원칙적으로 불가**하다.
- 공식 도메인 스니펫 1건 → `✅`
- 공식 도메인 스니펚 + 독립 공식 보도자료(예: SEMI 공식 + PR Newswire + 개최도시 공식) → 예외적으로 `✅✅` 인정 (복수 1등급 소스가 문자열까지 일치하는 경우에 한함)
- 집계 사이트만 존재 → `⚠` 고정 (v2 §3-E)

**해소 방법**: 환경의 네트워크 정책을 완화(도메인 허용)하면 공식 페이지 직접 확인으로 등급 승급 가능. Phase 2 착수 전 결정 필요.

### 이 축의 성과 평가
- **지부 권역 발굴이 크게 보강됐다.** WEFTEC의 뉴올리언스 이탈로 생긴 권역 콘텐츠 공백(v2 §4-D 우려)이 **휴스턴 4건 + 오스틴 1건 + 달라스 3건**으로 메워졌다.
- 특히 **NAPE Summit·Hydrogen Technology Expo(둘 다 2월 휴스턴 GRB)** 는 규모·산업 중요도 대비 GEP 노출이 낮은 유형으로, 지시하신 "숨은 전시"의 전형이다.
- **SXSW**는 GEP 성격(무역전시 중심)상 미수록 가능성이 높으나 한국 기업·기관 참가가 활발한 행사다. 콘텐츠 가치가 높다.
- 다만 **이 축 13건 중 ✅는 2건뿐**이다. 나머지는 컨벤션센터 캘린더·2차 출처 기반이라 Phase 2에서 공식 확인이 필요하다.
