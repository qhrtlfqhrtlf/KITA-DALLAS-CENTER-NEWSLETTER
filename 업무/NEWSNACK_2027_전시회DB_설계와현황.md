## 1. 열(컬럼) 설계 — 제안안 대비 검증 결과

제안하신 5개 열(`전시회명 / 개최일정 / 모집일정 / 지역 / GEP·외부`)을 실데이터에 적용해 본 결과, **그대로 쓰면 데이터가 틀어지는 지점이 3곳** 확인됐다.

### 🔴 추가한 열 — 없으면 데이터가 틀림

| 열 | 근거 (실제 발생 사례) |
|---|---|
| **개최주기** | 연1회 / 격년(홀수년) / 격년(짝수년) / 3년주기 |
| **2027개최여부** | `개최` / `❌ 미개최`. **GEP가 "2027 Modex"를 수록했으나 MODEX는 2027년에 열리지 않는다.** 이 열이 없으면 존재하지 않는 전시가 평범한 한 행으로 들어앉는다. IMTS·CONEXPO도 동일 |
| **일자확정여부** | `확정 / 월단위추정 / 미정 / 해당없음`. GEP 105건 중 **37건이 "2027-01-01~2027-01-31" 형태의 월 단위 플레이스홀더**다. `개최일정` 한 칸에 넣으면 **1월 1일 개최로 오독**된다 |
| **회의시작·종료일 / 전시시작·종료일 (4열 분리)** | 2026 조사에서 날짜 상충의 최대 원인. 2027 데이터에서도 이미 발생 — NADA(회의 2/17–20 vs 전시 2/18–20), ISC West(회의 4/5–9 vs 전시 4/7–9), WEFTEC(회의 9/25–29 vs 전시 9/27–29) |

### 🟠 수정한 열

| 제안 | 수정 | 근거 |
|---|---|---|
| `개최일정` (1칸) | **시작일 / 종료일 분리** | 월별 정렬·필터 불가. 월별 콘텐츠 생성이 목적이므로 치명적 |
| `모집일정` | **한국관모집상태 + 한국관운영기관** | **GEP 114건 전부 모집시작·종료일자가 공란**이다. 날짜 칸으로 두면 100% 빈 열이 된다. `미게시 / 게시됨(URL) / 해당없음` 상태값이 실용적이며, v2 §8 타이밍 분석상 2027 하반기 공고는 조사 시점에 존재하지 않는 게 정상 |
| `지역` | **도시 / 주 / 전시장 분리** | 2026 조사에서 장소 오류 3건 발생. 전시장이 별도 칸이어야 검증·정정이 가능 |
| `GEP/외부` | **GEP / 외부 / 양쪽(교차일치) / 양쪽(⚠GEP오류)** | 2값이 아니라 4값. **"양쪽(교차일치)"이 곧 교차검증 완료 신호**이며 신뢰도의 핵심 지표가 된다. GEP 오류 건은 별도 값으로 표시해야 추적된다 |

### 🟡 추가한 보조 열
`검증등급(✅✅/✅/⚠)` · `공식URL` · `확인일자` · `산업분야` · `전시회명(국문)` · `규모` · `규모기준연도`

- **확인일자**: 2027 정보는 활용 시점까지 최대 1년 시차가 생긴다. 없으면 무엇을 재확인할지 판단 불가
- **규모기준연도**: GEP 개최규모에 **기준 연도가 없다.** "2,000,000 sqft"가 몇 년 실적인지 알 수 없어 그대로 인용 불가

### 최종 23개 열
```
No / 전시회명(영문) / 전시회명(국문) /
회의시작일 / 회의종료일 / 전시시작일 / 전시종료일 / 일자확정여부 /
개최주기 / 2027개최여부 /
도시 / 주 / 전시장 / 산업분야 /
규모 / 규모기준연도 /
한국관모집상태 / 한국관운영기관 /
출처구분 / 검증등급 / 공식URL / 확인일자 / 비고
```
