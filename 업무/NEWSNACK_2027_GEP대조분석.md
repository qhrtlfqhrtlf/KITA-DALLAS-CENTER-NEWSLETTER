## 결론 먼저

**GEP를 뼈대로 쓰되, 단독으로 쓰면 지부 콘텐츠는 성립하지 않는다.** 세 가지 이유가 데이터로 확인됐다.

1. **지부 권역이 구조적으로 부재** — 미국 114건 중 텍사스 **0건**, 권역 전체로 넓혀도 뉴올리언스 1건뿐(0.9%)
2. **개최 주기 오류** — 격년제 전시를 개최하지 않는 해에 수록 (MODEX 2027, 실제 미개최)
3. **일자 정밀도 부족** — 114건 중 **37건(32%)이 개최미정**, 날짜가 "2027-01-01~01-31" 형태의 월 단위 플레이스홀더

지시하신 "KOTRA 공기관 운영이라 현지 반영이 느릴 수 있다"는 판단이 **데이터로 확인됐다.** 다만 지연보다 더 큰 문제는 **수집 범위의 편중**이었다.

## 4. GEP 데이터의 유용한 부분 (버리지 말 것)

- **전시회 설명·전시품목·산업분야** — 한국어로 정리돼 있어 NEWSNACK 콘텐츠 문안 초안에 바로 활용 가능
- **개최규모(sqft/㎡)** — 단 **기준 연도가 명시되지 않음**. v2 §5 "연도 라벨 필수" 규칙상 그대로 쓸 수 없고, 비고란의 실적 서술(예: CPNA "2025년 기준 참관객 19,000명·900개사·115개국")을 근거로 연도를 붙여야 함
- **비고란** — 주최측 성과 비공개 여부, 차년도 일정 미확정 여부가 기재돼 있어 **⚠ 미확인 판정의 근거로 쓸 수 있다**
- **무역관 정보** — 한국관 문의처 파악에 유용

## 5. GEP 데이터의 사용 제한

- **모집시작·종료일자 114건 전부 공란** → v2 §8 "2027 공고 상태"는 GEP로 확인 불가. KOTRA 해외시장뉴스·모집공고를 별도 조회해야 함 (v2 §8 예측대로 조사 시점상 대부분 미게시로 예상)
- **개최미정 37건은 일자 근거로 사용 금지** — 월 단위 플레이스홀더를 실제 일자로 오독하면 안 됨
- **v2 §6 위계상 GEP는 "한국관 정보 전용 1등급"** 이며, 일자·장소는 반드시 공식 사이트와 교차해야 채택 가능

## 6. 대조로 확정된 사실 (교차 일치 → 등급 승급)
