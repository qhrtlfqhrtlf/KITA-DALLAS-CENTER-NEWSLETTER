# Trade Newsline 발송용 HTML 자동화 — 인수인계 안내

이 폴더는 담당자가 바뀔 때 "뉴스레터 발송용 HTML을 계속 만들려면 무엇이 필요한지"를 한 곳에 모아둔 것입니다.
2026년 7월, 기존 IT 운영센터 SR 요청 방식을 대체하는 자체 자동화 도구가 만들어졌습니다.

## 1. 처음 받았을 때 할 일 (체크리스트)

받은 즉시 순서대로:

1. **Claude Code 설치 확인** — 이 도구는 Claude Code 안에서만 동작합니다. 없으면 먼저 설치.
2. **`코드\` 폴더를 본인 PC 작업 위치로 복사** (또는 GitHub에서 clone — 2번 항목 참고)
3. **Python 의존성 설치**
   ```
   cd (코드 폴더 경로)/scripts
   pip install -r requirements.txt
   ```
4. **Claude Code로 그 폴더 열기** — 터미널에서 `코드\` 폴더로 이동한 뒤 `claude` 실행 (또는 IDE 확장에서 해당 폴더를 열기)
5. **스킬 인식 확인** — Claude에게 아무 말이나 걸어보고, 사용 가능한 스킬 목록에 `html변환`이 뜨는지 확인 (`.claude/skills/html변환/SKILL.md`를 자동으로 읽어옵니다. 안 뜨면 폴더를 잘못 열었거나 `.claude` 폴더가 안 딸려온 것)
6. **동작 검증 (선택)** — `pytest tests/` 실행해서 13개 테스트가 다 통과하는지 확인. 통과하면 환경 설정이 제대로 된 것.
7. **계정 확보** — 2번 표에 나온 Constant Contact / 발송 CMS 계정을 관리자에게 요청 (이게 없으면 코드는 돌아가도 실제 발송까지는 못 감)
8. **실제 사용 시작** — 5번 "기본 사용법" 절차대로 `/html변환` 실행

여기까지 되면 준비 완료입니다. 막히는 부분이 있으면 `docs/superpowers/specs/`, `docs/superpowers/plans/`에 설계 배경이 남아있으니 참고하세요.

## 2. 코드 — 두 가지 경로 중 편한 쪽으로

**(A) GitHub 계정이 있는 경우**
```
git clone https://github.com/qhrtlfqhrtlf/KITA-DALLAS-CENTER-NEWSLETTER.git
```

**(B) GitHub 계정이 없어도 됨 — 이 폴더의 `코드\` 하위에 전체 사본이 이미 들어있음**
바로 옆 `코드\` 폴더를 그대로 통째로 복사해서 쓰면 됩니다. GitHub 없이도 100% 동일하게 동작 (직접 테스트로 확인 완료: `pytest tests/` 13개 전부 통과).

받은 뒤 공통:
```
cd (코드 폴더 경로)/scripts
pip install -r requirements.txt
```

핵심 파일 (두 경로 모두 동일한 구조):
- `scripts/newsletter_html.py` — render(스티칭 이미지) / build(발송용 HTML) / preview(검수용) / pages(예외 시 IT SR용 PNG 5장)
- `scripts/templates/newsletter_map.json` — 클릭영역 18개 좌표·링크 템플릿 (매 호 기준값)
- `.claude/skills/html변환/SKILL.md` — Claude Code에서 `/html변환` 커맨드로 실행되는 실제 작업 절차
- `docs/superpowers/specs/`, `docs/superpowers/plans/` — 왜 이렇게 만들었는지에 대한 설계 배경

**이 도구는 Claude Code(또는 호환 AI 코딩 도구) 안에서 `/html변환` 커맨드로 사용합니다.** 새 담당자도 Claude Code 설치가 필요합니다.

⚠️ (B) 로컬 사본은 스냅샷입니다. GitHub에 새 커밋이 올라가도 자동 반영되지 않으니, 시간이 지나면 (A) 방식으로 최신 버전을 다시 받는 걸 권장합니다.

## 3. 코드에 없는 것 — 별도로 전달받아야 함 (git에 올리지 않음, 보안상 의도적 제외)

| 항목 | 용도 | 전달 방법 |
|---|---|---|
| **Constant Contact 로그인** | 이너 PDF + 커버 이미지 업로드, 발송용 URL 생성 | 계정 관리자(현재 정민우 GM 등)에게 문의 / 비밀번호 관리 도구로 전달 |
| **뉴스레터 실제 발송 CMS 계정** ("해외지역본부〉댈러스지부" 권한) | 완성된 HTML을 최종 붙여넣어 발송 등록 | IT 운영센터 또는 전임자에게 계정 인계 요청 |
| **KIWI 포털 계정** | (예외 상황 전용) 자체 생성이 막힐 때만 IT SR 요청 | 사내 계정, 통상 입사 시 발급 |

⚠️ 비밀번호/토큰은 이 폴더나 git에 절대 적어두지 않습니다. 계정 인계는 IT/관리자를 통해 별도로 진행하세요.

## 5. 기본 사용법

1. 커버 PDF, 이너 PDF 완성
2. Constant Contact에 이너 PDF + 커버 스티칭 이미지 업로드 → 각각 URL 확보
3. Claude Code에서 `/html변환 [커버 PDF 경로]` 실행 → 발행일, CC URL 입력하면 대화형으로 진행
4. 검수(preview.html) 통과 후 완성된 HTML을 발송 CMS에 붙여넣기

자세한 단계별 절차는 `.claude/skills/html변환/SKILL.md` 참고 (Claude가 자동으로 읽습니다).
