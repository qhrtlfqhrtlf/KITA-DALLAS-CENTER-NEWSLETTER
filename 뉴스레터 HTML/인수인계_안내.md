# Trade Newsline 발송용 HTML 자동화 — 인수인계 안내

이 폴더는 담당자가 바뀔 때 "뉴스레터 발송용 HTML을 계속 만들려면 무엇이 필요한지"를 한 곳에 모아둔 것입니다.
2026년 7월, 기존 IT 운영센터 SR 요청 방식을 대체하는 자체 자동화 도구가 만들어졌습니다.

## 1. 처음 받았을 때 할 일 (스텝바이스텝)

**범례** — 각 단계 앞에 어디서 하는 작업인지 표시:
🖥️ = **PowerShell/터미널**에 직접 타이핑 (Claude Code 실행 전)
💬 = **Claude Code 채팅창**에 자연어로 요청
👤 = 사람이 직접 처리 (계정 신청 등, 터미널/Claude와 무관)

---

### 1단계 🖥️ Claude Code 설치 확인

```powershell
claude --version
```
- 버전이 뜨면 설치돼 있는 것 → 3단계로
- `claude: 명령을 찾을 수 없습니다` 등 오류가 뜨면 미설치 → https://claude.com/claude-code 안내에 따라 설치 후 터미널을 재시작하고 위 명령으로 재확인

### 2단계 🖥️ 또는 👤 코드 폴더 준비

두 방법 중 하나:
- **GitHub이 있는 경우** (🖥️ PowerShell):
  ```powershell
  git clone https://github.com/qhrtlfqhrtlf/KITA-DALLAS-CENTER-NEWSLETTER.git
  ```
- **GitHub이 없는 경우** (👤 파일 탐색기): 전달받은 `코드\` 폴더를 본인 PC의 원하는 위치(예: 바탕화면)로 그냥 복사-붙여넣기

이후 단계에서 이 폴더 경로를 `<코드폴더>`로 표기합니다.

### 3단계 🖥️ Python 및 패키지 설치

```powershell
python --version
```
- 버전이 안 뜨면 Python 미설치 → https://www.python.org/downloads/ 에서 설치 (설치 시 "Add python.exe to PATH" 체크 필수) 후 터미널 재시작

Python 설치 확인됐으면 패키지 설치:
```powershell
cd "<코드폴더>\scripts"
pip install -r requirements.txt
```
- 마지막 줄에 `Successfully installed ...` 뜨면 성공

### 4단계 🖥️ Claude Code 실행 (코드 폴더 자체를 열기)

```powershell
cd "<코드폴더>"
claude
```
- `<코드폴더>\scripts`가 아니라 **그 상위 폴더**(`.claude`, `scripts`, `tests`가 나란히 있는 위치)에서 실행해야 함
- Claude Code 채팅 화면이 뜨면 성공 — 여기부터는 💬 단계

### 5단계 💬 스킬 인식 확인

채팅창에 아무 메시지나 입력 (예: "안녕")
- 시스템이 인식한 사용 가능한 스킬 목록에 **`html변환`** 이 보이면 정상
- 안 보이면: 4단계에서 폴더를 잘못 열었거나(예: scripts 폴더 안에서 실행), `.claude` 폴더가 복사 과정에서 누락된 것 → 2단계부터 재확인 (`.claude`는 숨김 폴더라 복사 시 파일 탐색기에서 "숨김 항목 표시"를 켜야 보일 수 있음)

### 6단계 💬 또는 🖥️ 동작 검증 (선택)

둘 중 편한 방법으로:
- 🖥️ 터미널: `<코드폴더>`에서 `pytest tests/`
- 💬 채팅창: "pytest tests/ 실행해줘"

결과가 `13 passed`면 환경 설정 완료.

### 7단계 👤 계정 확보

아래 3번 항목 표에 나온 **Constant Contact 로그인**, **뉴스레터 발송 CMS 계정**을 관리자에게 요청해서 받기. (코드는 이미 다 됐어도 이 계정이 없으면 실제 발송까지는 못 갑니다.)

### 8단계 💬 실제 사용 시작

채팅창에:
```
/html변환 <이번 호 커버 PDF 경로>
```
이후는 Claude가 대화형으로 발행일·CC URL 등을 물어보며 진행합니다. 자세한 절차는 5번 "기본 사용법" 참고.

## 2. 코드 — 두 가지 경로 중 편한 쪽으로

**(A) GitHub 계정이 있는 경우**
```
git clone https://github.com/qhrtlfqhrtlf/KITA-DALLAS-CENTER-NEWSLETTER.git
```

**(B) GitHub 계정이 없어도 됨 — 이 폴더의 `코드\` 하위에 전체 사본이 이미 들어있음**
바로 옆 `코드\` 폴더를 그대로 통째로 복사해서 쓰면 됩니다. GitHub 없이도 100% 동일하게 동작 (직접 테스트로 확인 완료: `pytest tests/` 13개 전부 통과).

받은 뒤 공통:
```
cd (코드 폴더 경로)/scripts
pip install -r requirements.txt
```

핵심 파일 (두 경로 모두 동일한 구조):
- `scripts/newsletter_html.py` — render(스티칭 이미지) / build(발송용 HTML) / preview(검수용) / pages(예외 시 IT SR용 PNG 5장)
- `scripts/templates/newsletter_map.json` — 클릭영역 18개 좌표·링크 템플릿 (매 호 기준값)
- `.claude/skills/html변환/SKILL.md` — Claude Code에서 `/html변환` 커맨드로 실행되는 실제 작업 절차
- `docs/superpowers/specs/`, `docs/superpowers/plans/` — 왜 이렇게 만들었는지에 대한 설계 배경

**이 도구는 Claude Code(또는 호환 AI 코딩 도구) 안에서 `/html변환` 커맨드로 사용합니다.** 새 담당자도 Claude Code 설치가 필요합니다.

⚠️ (B) 로컬 사본은 스냅샷입니다. GitHub에 새 커밋이 올라가도 자동 반영되지 않으니, 시간이 지나면 (A) 방식으로 최신 버전을 다시 받는 걸 권장합니다.

## 3. 코드에 없는 것 — 별도로 전달받아야 함 (git에 올리지 않음, 보안상 의도적 제외)

| 항목 | 용도 | 전달 방법 |
|---|---|---|
| **Constant Contact 로그인** | 이너 PDF + 커버 이미지 업로드, 발송용 URL 생성 | 계정 관리자(현재 정민우 GM 등)에게 문의 / 비밀번호 관리 도구로 전달 |
| **뉴스레터 실제 발송 CMS 계정** ("해외지역본부〉댈러스지부" 권한) | 완성된 HTML을 최종 붙여넣어 발송 등록 | IT 운영센터 또는 전임자에게 계정 인계 요청 |
| **KIWI 포털 계정** | (예외 상황 전용) 자체 생성이 막힐 때만 IT SR 요청 | 사내 계정, 통상 입사 시 발급 |

⚠️ 비밀번호/토큰은 이 폴더나 git에 절대 적어두지 않습니다. 계정 인계는 IT/관리자를 통해 별도로 진행하세요.

## 5. 기본 사용법

1. 커버 PDF, 이너 PDF 완성
2. Constant Contact에 이너 PDF + 커버 스티칭 이미지 업로드 → 각각 URL 확보
3. Claude Code에서 `/html변환 [커버 PDF 경로]` 실행 → 발행일, CC URL 입력하면 대화형으로 진행
4. 검수(preview.html) 통과 후 완성된 HTML을 발송 CMS에 붙여넣기

자세한 단계별 절차는 `.claude/skills/html변환/SKILL.md` 참고 (Claude가 자동으로 읽습니다).
