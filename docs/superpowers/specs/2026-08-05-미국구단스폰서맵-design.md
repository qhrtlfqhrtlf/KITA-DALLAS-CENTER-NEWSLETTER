# 미국 구단·스폰서 지도 — 조사 및 산출물 설계

- 작성일: 2026-08-05
- 담당: 김태헌 (KITA Dallas Center)
- 목적: 인스타그램 정보전달 콘텐츠 신규 시작. "미국 지역별로 어떤 구단이 있고 어떤 기업이 스폰하는가"를 생활 밀접 관점으로 정리
- 톤: 가벼운 주제. 산업 분석 리포트가 아니라 "이 로고, 우리가 매일 보는 그 회사" 류의 생활 밀접 정보 콘텐츠

## 2. 조사 스키마

구단 단위 정보(A·C)와 스폰서 단위 정보(B)를 분리한다.
스폰서는 구단당 주요 3~5곳을 선정해 **각각** B의 5개 필드를 채운다.
13개 구단 × 3~5곳 = 약 50개 스폰서 항목.

### A. 구단 기본

1. 창단연도
2. 연고지 (구단명의 도시와 실제 구장 소재 도시가 다른 경우 병기 — 예: Rangers는 Arlington)
3. 구단주
4. 홈구장명 + 소재 도시

### B. 스폰서 개별 항목 (스폰서 1곳당)

| 필드 | 내용 |
|---|---|
| 기업명 / 업종 | 스폰서 주체. 업종은 고정 분류 사용 (§4) |
| 계약 금액·기간 | 총액, 연평균, 계약 기간, 갱신 시점. 공개 등급 병기 (§3) |
| 노출 영역 | 로고·브랜드가 실제로 붙는 위치 — 구장명, 유니폼 패치, 코트·필드 사이드 LED, 티켓·구단 앱, 중계 방송 그래픽, 콘코스 라운지·게이트, 매점 브랜딩 |
| 스폰서가 하는 일 | 돈만 내는지 vs 실제로 무엇을 제공·운영하는지 — 기술·인프라 제공, 결제 시스템, 유니폼·장비 공급, 팬 리워드·멤버십, 지역 사회 프로그램 |
| 팬 접점 | 관중이 체감하는 지점 1줄 |

### C. 해석 레이어 (구단 단위)

1. 한국 기업 관련 여부 — 해당하는 경우에만 기재. 메인 서사는 미국 기업이며, 한국 기업은 플래그 처리
2. 생활 밀접 포인트 1줄 — 카드뉴스 카피의 원재료
3. 도시별 업종 분포 — 텍사스는 에너지·항공이 두드러질 것으로 예상되나 **검증 대상**이며 결론을 미리 쓰지 않음

## 3. 데이터 신뢰도 원칙

스폰서 계약금액은 공식 비공개가 원칙이다. 모든 금액 항목에 공개 등급을 반드시 표기한다.

| 등급 | 조건 | 표기 |
|---|---|---|
| `공식 발표` | 구단 또는 기업 보도자료로 확인 | 출처 URL |
| `언론 보도` | 매체 보도만 존재 | 매체명 + 보도일 병기 |
| `미공개` | 확인 불가 | 공란 |

**추정치를 만들어 채우지 않는다.** 미공개는 미공개로 남기고 보고서에 그 사실을 명시한다.

### 출처 우선순위

1. 1차 — 구단 공식 사이트, 구장 공식 사이트, 리그 공식 파트너 페이지
2. 2차 — Sportico, Sports Business Journal, SponsorUnited
3. 3차 — 지역 언론 (Dallas Morning News, Houston Chronicle 등)

### 사전 확인이 필요한 항목 (조사 시작 시 최우선 검증)

- Houston Astros 홈구장 개칭 여부 (Minute Maid Park → Daikin Park) 및 시점
- Dallas Wings 현재 홈구장
- 리그별 유니폼 패치 규정 차이 (NBA·NHL·MLB·MLS가 각각 다름 — 없는 리그는 "해당 없음"으로 명시)

## 5. 산출물

### ① 데이터 파일 — 단일 원본

- 경로: `업무/인스타-정보전달/미국구단스폰서맵/데이터.json`
- 보고서와 대시보드가 **모두 이 파일만 참조**한다. 숫자를 두 곳에 손으로 적지 않음으로써 불일치를 원천 차단
- 구조: 구단 배열, 각 구단이 스폰서 배열을 가짐. §2의 필드명을 그대로 키로 사용

### ② 조사 보고서 (내부 문서)

- 경로: `업무/인스타-정보전달/미국구단스폰서맵/조사보고서.md`
- 구성
  1. 개요 및 조사 범위
  2. 도시별 섹션 (DFW → 휴스턴 → 샌안토니오 → 오스틴), 구단별 A·B·C 전개
  3. 업종 분포 요약 (검증된 데이터 기준)
  4. 미공개·미확인 항목 목록 — 무엇을 확인하지 못했는지 명시
  5. 출처 목록

### ③ 인터랙티브 대시보드

- 경로: `업무/인스타-정보전달/미국구단스폰서맵/대시보드.html`
- 단일 HTML 파일, 외부 CDN 의존 없이 자체 완결
- 텍사스 주 지도 SVG + 4개 도시 핀 → 도시 클릭 시 해당 도시 구단 카드 패널 표시
- 카드 내용: 구장명, 네이밍 라이츠 기업, 스폰서 목록(업종 색상 배지), 계약 정보, 노출 영역, 스폰서가 하는 일
- **스폰서 기업 로고는 사용하지 않는다.** 텍스트 + §4 업종 색상 배지로 처리
- **구단 표식은 구단 상징색 + 3글자 약칭 배지를 기본으로 한다** (2026-08-11 확정).
  구단 로고 이미지를 쓰는 방안을 검토했으나, 로고 파일을 조달할 수단이 없어
  (이미지 바이너리를 저장할 수 없음) 색+약칭 배지로 확정했다.
  단 `로고/<약칭>.png` 파일을 넣으면 생성 시 base64로 HTML에 박아 로고 배지로
  렌더하는 경로는 남겨 두었고, 파일이 없는 구단은 색+약칭 배지로 자동 대체된다.
  로고를 넣을 경우 등록 상표이므로 외부 발행물(카드뉴스 등)에는 사용 조건을 별도 확인한다.
- Phase 2 확장 시 지도 SVG만 교체하고 카드 렌더링 구조는 재사용

### ④ 카드뉴스 — 본 스펙 범위 외

보고서 확정 후 `/카드뉴스` 스킬로 별도 진행.
